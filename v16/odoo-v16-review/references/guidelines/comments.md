# Comentarios y mensajes

Explica decisiones, contratos y causas no evidentes. Mantén el idioma y el estilo
del proyecto; las preferencias tipográficas del core no son requisitos técnicos
para todos los addons. No reescribas literales traducibles por un cambio cosmético.

Los mensajes al usuario describen el problema y la acción útil, con placeholders
traducibles. Evita registrar secretos, credenciales o payloads completos.
